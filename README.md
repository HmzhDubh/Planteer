# PLANTEER
## Using React and redux to build new website called "Planteer".

## Features 
- interactive Home page
- Plants complete data and images
- Plant Detail
- Easy to add new plants
- Easy to update plant
- Delete Plant easily
- Search for plants
- Contact Us form
- testimonials

### Specifications:
- Use of react & Redux.
- Responsive web app
- Tailwind CSS
